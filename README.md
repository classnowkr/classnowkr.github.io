# 클래스 나우 (구글 드라이브판)

담임 선생님이 교실 TV(전자칠판)에 공지 · 설문 · 투표 · 시간표를 띄우고, 학생이 TV에서 답한 결과를 컴퓨터로 확인하는 학급 운영 프로그램입니다.

- 바로 쓰기: https://classnowkr.github.io
- 교실 TV 앱: https://classnowkr.github.io/tv.apk
- 개인정보 처리방침: https://classnowkr.github.io/privacy.html

제작자 서버가 없습니다. 학급 자료는 담임 선생님 본인 구글 드라이브의 '앱 전용 숨은 폴더'에만 저장됩니다.

이 저장소의 화면 파일은 원본(yjb8634-sudo/class-diary 의 classroom-drive)에서 매시간 자동으로 받아 옵니다.
